### S01 仰望（冷开场）

- **场号/年代戳/地名**：S01 · `C. 40,000 BCE` · 旧石器时代 · 星空下
- **画面描述**：写实夜空满幅：银河横贯，星斗低垂；洞穴口一簇火堆，一个人影剪影坐在火旁，仰着头，看了很久；火光与星光两种色温交融。群星中**最亮的一颗泛着极淡的珊瑚色**，是全场唯一暖色星点。胶片颗粒+暗角，极缓推镜（或星野极缓旋转——图生视频候选）。
- **画风**：写实星空 + 火堆剪影（无脸）
- **构图指令**：星空占上 2/3，人影剪影在左下三分线上、面向右上的最亮星；火堆光晕限制在左下角；铭牌左上；底部字幕区避开剪影。运动层=星点微闪 + 火光摇曳。
- **字幕1（中/英）**：`四万年前，有人第一次抬头，看了很久。`（18字） / *Someone looked up, and looked for a long time.*
- **字幕2（中/英）**：`头顶的星空，是第一块屏幕。`（13字） / *The first screen was the sky.*
- **情绪锚点**：好奇——第一次"读取"世界（叙述者的回望式修辞）
- **该场唯一事实**：旧石器时代晚期（约4万年前）人类已具备象征与观察能力（同期洞穴壁画为实证锚）。
- **fact_refs**：`paleolithic-stargazing-40000bce`
- **rhetoric_flag**：**true**（"第一次仰望"为演绎；实证锚=同期壁画，facts 条目注明）

### S03 数沙者（阿基米德）

- **场号/年代戳/地名**：S03 · `III CENTURY BCE` · 叙拉古 · 数沙
- **画面描述**：暖沙满幅：上 1/3 暮色初星（呼应 S01 星空），下 2/3 暖沙。**全剪影无脸**：阿基米德蹲踞的剪影在沙中，指尖把散沙一粒粒归拢，沙粒垒成一座不断长高的**层级塔**（万 → 万×万 → 万×万×万……量级逐层上叠，塔影渐与暮空相接）；尾声塔身散落，沙面中央浮现一个发光的刻印——**球与外切圆柱**（他要求刻在墓上的图形），图形的圆心一点珊瑚红。
- **画风**：暖沙极简 + 皮影/剪影戏 + 暮空初星（保留 v2.1 画风骨架，叙事由"殉道"改为"数沙"）
- **构图指令**：暮空占上 1/3，最亮一颗初星在中上偏右；剪影居左 35%；层级塔自沙面中部向右上升高，塔顶不超过上 1/3 线；球与圆柱刻印收束在画面中下 40% 处居中；铭牌左上。运动层=沙粒归拢 + 塔身逐层生长 + 刻印描边浮现。
- **字幕1（中/英）**：`把宇宙装满沙粒，谁来数到尽头？`（15字） / *Fill the universe with sand — who could count it to the end?*

- **情绪锚点**：狂妄的庄严——第一个把宇宙装进记数系统的人（承上 S01：他数的就是星空的大小；启下 S06：8×10⁶³ 是必须先有"位"才写得出来的数）

### S04 零（婆罗摩笈多）

- **场号/年代戳/地名**：S04 · `628` · 比尔马尔 · 空位上的点
- **画面描述**：暗底极简：一排算筹/数位槽横陈画面中部，其他槽里都卧着沙粒（计数的实有），只有最右一槽是**空的**；一只手（剪影）自右上落下，在空位上点下一个**圆点**——圆点亮起一点珊瑚红，泛起微光涟漪。全场唯一的暖色，就是这一点"没有"。
- **画风**：暗底算筹/数位槽 + 剪影（印度 7 世纪天文台意象，抽象化处理）
- **构图指令**：数位槽横带在画面中 45%；空槽在右 70% 处；手部剪影自右上 30% 处落下；圆点=✳母题位置（全片 ✳ 的祖先）；铭牌左上。运动层=沙粒微颤 + 圆点涟漪。
- **字幕1（中/英）**：`公元六二八年，"没有"，第一次有了名字。`（20字） / *In 628, "nothing" was given a name.*
- **字幕2（中/英）**：`他连零除以零都敢算——虽然，他算错了。`（18字） / *He even tried 0 ÷ 0 — and got it wrong.*
- **情绪锚点**：谦卑的胆识——第一个给"没有"命名的人，也第一个在新数上算错（与 S03 成对：给极大造语言 ↔ 给空无造符号；直接回收于 S06 的「0」「1」两字）
- **该场唯一事实**：628 年婆罗摩笈多《婆罗摩历算书》首次把零作为一个数给出运算规则（零加减乘法则）；并给出 0÷0=0 的错误规则——0÷0 实为不定，后世印度数学家修正；零的概念根植于印度"空"（śūnya）哲学。
- **fact_refs**：`brahmagupta-zero-628`
- **rhetoric_flag**：false（全部史实；"算错了"是其著作原文规则的直陈）
- **v2.2 注**：本场由花拉子米改写——波斯细密画与原片撞车弃用；"算法"接力棒叙事让位于更硬的一根：人类第一次给"没有"一个数字身份。
